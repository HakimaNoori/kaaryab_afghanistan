# KaarYab Afghanistan - Opportunity Finder Platform

A modern web application that helps Afghan youth discover jobs, internships, scholarships, remote work, online courses, and skill-building opportunities in one place.

## Problem It Solves

Information about opportunities in Afghanistan is often scattered across different websites, social media pages, and groups. This makes it difficult for students and job seekers to find useful opportunities. KaarYab brings everything together in a clean and easy-to-use platform.

## Features

- Browse and search opportunities
- Filter by category, type, and location
- View detailed opportunity pages
- Save opportunities (LocalStorage)
- Add new opportunities with form validation
- Delete opportunities
- Dashboard with live statistics
- Dark Mode support
- Fully responsive design (Mobile, Tablet, Desktop)

## Technologies Used

- Next.js 15 (App Router)
- React
- TypeScript
- Tailwind CSS
- React Hook Form + Zod
- Context API + LocalStorage
- Lucide React (Icons)
